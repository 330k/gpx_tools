# gpx_tools
GPX Tools on Web Browser

## Browser Apps
* Reduce points and child nodes: https://330k.github.io/gpx_tools/gpx_simplify.html
  * Main Page: https://www.330k.info/software/simplify_gpx/
* GPX to FIT Converter: https://330k.github.io/gpx_tools/gpx_tcx_converter.html
  * Main Page: https://www.330k.info/software/gpx-tcx-converter/
* Check difference between 2 GPX routes: https://330k.github.io/gpx_tools/gpx_compare.html
  * Main Page: https://www.330k.info/software/gpx-compare/
* Detect spikes of GPX route: https://330k.github.io/gpx_tools/gpx_spike_detector.html
  * Main Page: https://www.330k.info/software/gpx-spike-detector/
* Draw graph: https://330k.github.io/gpx_tools/gpx_visualize.html

## Google Site Gadgets
* Add elevation to gpx points: https://330k.github.io/gpx_tools/add_elevation_to_gpx_gadget.xml
